Install DuoScore

DuoScore is a real Android app now. Download it once — then it works with no internet, saves everything, and lives on your home screen.

Download DuoScore app4 MB · Android phone / tablet
  1. Tap the red button above
  2. If Chrome says can’t download securely — tap ⋮ → Download anyway
  3. When it’s done, tap the downloaded file
  4. Android will ask to allow unknown apps — allow it, then Install
  5. Open DuoScore and start playing

No download button visible? Open this page in another browser (Firefox, Opera, Samsung Internet, Edge) and the button will work.

Or play it right now in the browser: open DuoScore — in Chrome you can also tap ⋮ → Add to Home screen for an app-style icon.

⚠️ Play Protect may warn about an unknown developer — this is Dali’s own app, it only keeps score in your phone’s storage. Tap “Install anyway” if you see it.
